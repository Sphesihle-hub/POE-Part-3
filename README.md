📌 Project Overview

Kwa-Mzilikazi is a traditional home-style eatery located at 43 Eloff Street, Gandhi Square Precinct, Johannesburg CBD. The website showcases authentic South African meals (such as beef stew, mogodu, and inhloko), fresh meat bones sold by the kilogram, and cold refreshments. It is designed with a culturally rich Zulu traditional aesthetic, utilizing parchment tones, terracotta accents, and geometric beadwork patterns.

🚀 Features & Functionality

Part 1 & 2: Structure & Styling

5 Fully Responsive Pages: Home, About Us, Menu, Enquire, and Contact Us.

Zulu Heritage Theme: Custom CSS custom properties, parchment background textures, and geometric beadwork header/footer borders.

Advanced Grid & Flexbox Layouts: Modern CSS Grid architecture for headers and content alignment.

Part 3: Interactivity, SEO & Forms

Live Menu Search Bar: Real-time filtering of menu items as users type.

Interactive Image Lightbox: Clickable gallery zoom modal for all food and storefront images.

Client-Side Form Validation: JavaScript validation for names, phone numbers, and email formats on both the Enquiry and Contact forms.

Dynamic Cost/Availability Responses: Instant JavaScript feedback calculations based on user enquiry types.

On-Page & Technical SEO: Optimized meta descriptions, structured heading hierarchy (H1, H2, H3), descriptive image alt texts, and internal linking.
